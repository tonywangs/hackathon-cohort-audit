# Synthetic examples

These are original generated records, not real hackathons, projects, people or
observed trends. Source URLs use the reserved `.invalid` domain. The hostile-looking
HTML in one title/label is intentional test data and must render as literal text.

Regenerate exactly with `python3 scripts/make_example.py`. The generator is a fixed
construction, not random. `provenance.json` records SHA-256 hashes, selection rules,
license and expected aggregate/event rates. All generated rows are included.
